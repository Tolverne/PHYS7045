Question 1. 
 
A code defined on five qubits has the following stabiliser generators 
 
𝑆! = 𝑍 𝑍 𝑍 𝐼 𝐼 
𝑆" = 𝐼 𝐼 𝑍 𝑍 𝑍 
𝑆# = 𝑋 𝐼 𝑋 𝑋 𝐼 
𝑆$ = 𝐼 𝑋 𝑋 𝐼 𝑋 
 
Part A (grade: 1-5) 
1. Do you expect 𝑆! to commute with all the other stabilisers listed in the table, or not? Explain 
your answer.  Confirm whether this is true (and show your reasoning). 
2. A logical 𝑋% operator is defined for this code as 𝑋% = 𝑋 𝑋 𝐼 𝐼 𝐼.  Verify whether this commutes 
with the stabilisers. 
3. Is this code able to detect a single qubit bit-flip error (i.e. an 𝑋 error) on any one qubit? Give 
reasons based on possible syndromes. Can it correct such an error? 
4. Is this code able to detect a single qubit phase error (i.e. a 𝑍 error) on any one qubit. Give 
reasons based on possible syndromes.  Can it correct such an error? 
5. Explain whether the code can correct any single qubit 𝑋, 𝑌 or 𝑍 error?  If so, what is the 
lower bound on the code distance? 
 
Part B (Advanced: grade +0,+1,+2)  
a) Find a logical 𝑍% operator for the code, and verify whether it has the correct commutation 
and anticommutation relations with the stabilisers and with 𝑋%. 
b) Calculate the code distance, and explain whether this is consistent with questions A3, A4 
and A5 above.

Question 3. 
 
The two atom Rydberg CNOT gate described in lectures used a series of sequential 
applications of localised pulses to the two atoms. Since there are technical challenges in 
implementing this approach, the use of simultaneous pulses can provide technical 
advantages. 
In the approach shown in the figure, a simultaneous |0⟩→|𝑟⟩ pulse Ω! is applied to two 
adjacent atoms, and a second |𝑟⟩→|1⟩ pulse Ω" is simultaneously applied to the second 
atom only. Note that applying the two wavelength pulses simultaneously results in a two-
photon transition, coupling the |1⟩ and |0⟩ states.  
 
Part A (grade: 1-5) 
1. What are the pulse areas needed (2𝜋, 𝜋, etc.) needed for the control and target pulses? 
Explain your answer. 
2. Assuming double-excitation to the Rydberg state is blockaded, show the effect of applying 
the pulse sequence on the qubit basis states |1*0+⟩, |1*1+⟩, |0*1+⟩, |0*0+⟩, demonstrating that 
this results in a CNOT gate. Explain your reasoning. 
3. In comparison to the scheme described in class, describe one technical advantage of this 
approach to realising a two-qubit gate with Rydberg atoms. 
 
Part B (Advanced: grade +0,+1,+2)  
a) Show how the above scheme can be used to realise a Toffoli gate with three qubits and the 
same global pulses, with Ω" again applied to the target only. Hint: consider the geometric 
arrangement of the atoms, noting that the Rydberg blockade applies to nearest neighbours.
