# Source material (keep originals here)

This is the **unmodified input library** for PHYS7045 revision: lecture transcripts, slides, assignments and past papers. Upload downloaded files to the appropriate folder without editing the originals.

Unlabelled lecture PDFs go into `lectures/notes_to_identify/`. They can later be identified and moved to `lectures/slides_and_handouts/` after comparing them to the transcripts. Use `lectures/lecture_index.csv` to record the lecture date, topic, source filenames and identification status.

The `past_exams/` directories contain **original papers**; your own step-by-step worked answers belong in `../exam_prep/worked_past_exams/`.
